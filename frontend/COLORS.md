# Project Color Reference

## Main Colors

| Color | Code | Used In |
|-------|------|---------|
| Gold / Tan | `#b8966e` | Logo, labels, artist count, login form accent |
| Dark text | `#1a1a1a` | Most text, buttons, active tabs, sort |
| Dark gray text | `#262626` | Art card title, artist, description |
| White | `#fff` | Landing hero text, login right side, hover buttons |
| Near black | `#0f0f0f` | Login / Signup left panel background |
